## 🔧 常用操作

### 导出打卡数据
```javascript
// 在浏览器控制台运行
copy(localStorage.getItem('fishrain_checkin'))
```

### 清除打卡数据
```javascript
localStorage.removeItem('fishrain_checkin')
```

### 恢复默认打卡数据
```javascript
localStorage.setItem('fishrain_checkin', 
  '{"totalDays":0,"currentStreak":0,"lastCheckIn":null,"checkinDates":[],"monthData":{}}')
```

### 查看所有数据
```javascript
console.log(JSON.parse(localStorage.getItem('fishrain_checkin')))
```

## ❓ 常见问题速答

**Q: 怎样开始使用？**  
A: 打开 about.html，向下滚动，点击打卡按钮即可。

**Q: 数据会丢失吗？**  
A: 不会，数据保存在浏览器本地，除非主动清除缓存。

**Q: 能在手机上用吗？**  
A: 可以，已做过响应式优化，完美支持手机。

**Q: 可以修改设置吗？**  
A: 可以，编辑 `js/config.js` 文件修改配置。

**Q: 数据能导出吗？**  
A: 可以，在浏览器控制台运行 JavaScript 代码导出。

**Q: 多个设备能同步吗？**  
A: 目前不行，每个浏览器/设备独立存储。
